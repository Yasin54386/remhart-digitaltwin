# Real-Time Voltage Anomaly Detection (VAD)

## 1. Overview
The **Voltage Anomaly Detection (VAD)** model is an unsupervised machine learning component of the **REMHART Digital Twin**. It is designed to identify "Contextual Anomalies"—irregularities that may fall within legal utility limits but represent significant risks to equipment health or indicate data integrity failures.

## 2. Model Logic: Unsupervised Multivariate Detection
Unlike traditional systems that use fixed high/low thresholds, this model utilizes the **Isolation Forest** algorithm to learn the "Normal Operational Envelope" of the three-phase system.

### A. Phase Symmetry Logic
In a healthy power system, the voltages across all three phases (`volt_A`, `volt_B`, `volt_C`) are physically bound by symmetry. The model identifies anomalies when:
* One phase deviates significantly from the others (Phase Unbalance).
* A single phase experiences a sag or surge that does not follow the system-wide trend.



### B. Socio-Temporal Correlation
Using **Social Seasonality** features (Hour of Day), the model differentiates between:
* **Normal Load Sags**: Predictable voltage drops during peak hours (e.g., 6:00 PM).
* **Anomalous Stability Breaks**: Sudden voltage shifts during low-demand periods (e.g., 3:00 AM) that do not match historical behavioral patterns.

### C. Explicit Feature Engineering
To enhance detection accuracy, the model incorporates the **Voltage Unbalance Factor (VUF%)** and **Hourly Stability Deltas**, ensuring it prioritizes phase asymmetry—the leading cause of motor and transformer degradation.



## 3. Business Value & Operational Impact
Implementing real-time voltage anomaly detection provides three critical business advantages:

| Value Pillar | Description |
| :--- | :--- |
| **Asset Longevity** | Detects **Phase Unbalance** and **Single-Phasing** precursors. Preventing these conditions can double the lifespan of motor windings by avoiding the heat generated by negative sequence currents. |
| **Grid Resilience** | Identifies "Soft Faults" and transient sags before they evolve into "Hard Faults" or total system outages, enabling proactive maintenance scheduling. |
| **Energy Loss Mitigation** | High-frequency voltage anomalies often correlate with **Non-Technical Losses (NTL)** or sensor degradation, allowing operators to verify meter accuracy and reduce unbilled energy consumption. |

## 4. Scientific Standards
The model logic is aligned with international power quality and monitoring standards:
* **IEEE 1159**: Standard for characterizing power quality variations.
* **IEC 61000-4-30**: Standard for power quality measurement methods.
* **IEEE Std 730**: Ensuring high-fidelity data integrity for predictive grid modeling.
